# 阶段 3 完成总结：数据流优化与可观测性增强

## 1. 阶段目标

阶段 3 的目标是在阶段 2“多传感器 DMA 集成”基础上，进一步提升系统数据流的**可观测性、可判定性和可测试性**，使系统不仅能够持续采样和记录，还能够明确判断：

1. 三路传感器数据是否持续更新
2. 每一行日志中哪些传感器是本轮新数据
3. 各路数据是否处于新鲜状态
4. 三路数据是否满足时间一致性要求
5. 用户是否能够通过 USB CDC / 串口直接判断系统是否处于健康工作状态

---

## 2. 本阶段完成内容

### 2.1 完成 snapshot 元数据增强

在共享 snapshot 结构中，为三路传感器都补充了以下元数据：

- `valid`
- `sample_seq`
- `last_update_ms`

实现结果：

- 每路传感器发布数据时，都会更新自身有效标志
- 每路传感器维护独立序号 `sample_seq`
- 每路传感器维护最近更新时间 `last_update_ms`

这使得应用层能够判断：

- 数据是否有效
- 数据是否持续变化
- 数据距离当前时间是否过旧

### 2.2 完成 logger 路径增强

在 SD 日志路径中，已增加阶段 3 的关键判定指标：

- `changed_mask`
- `fresh_mask`
- `coherent`
- `max_delta_ms`

同时保留原有原始传感器数据列。

实现结果：

- logger 在每次写行前，先拷贝 snapshot 到本地
- 再基于本地快照计算数据流状态
- 不直接在共享 snapshot 上做格式化输出，避免并发读取不一致

这样每行 CSV 都不再只是“传感器数值”，而是同时携带“这一行数据是否健康”的状态信息。

### 2.3 完成 CSV 可测试字段扩展

SD 卡日志文件表头已扩展，新增字段包括：

- `lsm_seq`
- `h3_seq`
- `qma_seq`
- `changed_mask`
- `fresh_mask`
- `coherent`
- `max_delta_ms`

实现结果：

- 日志文件可以直接用于离线判断
- 可以从 CSV 直接观察：
  - 三路数据是否持续更新
  - 哪些传感器在相邻日志行中发生变化
  - 是否存在 stale 数据
  - 三路数据时间差是否超出允许窗口

### 2.4 完成 USB CDC 观察命令增强

USB CDC 已支持并验证以下命令：

- `help`
- `status`
- `snapshot`
- `flowstat`
- `dmastat`
- `stat`

其中：

- `snapshot`：显示三路传感器的 `valid / seq / age / 数据值`
- `flowstat`：显示 logger 统计、freshness、changed mask、coherent 情况
- `stat` / `dmastat`：继续显示 DMA 运行情况

这意味着：

- 用户无需拔卡查看 SD 文件，也能直接判断系统健康状态
- 阶段 2 的 DMA 可观测能力在阶段 3 中被保留并继续可用

### 2.5 完成运行期 flow 统计

系统已增加运行期 flow 统计信息，包括：

- `lsm_updates`
- `h3_updates`
- `qma_updates`
- `logger_rows`
- `logger_write_failures`
- `stale_rows`
- `mixed_rows`
- `coherent_rows`
- `last_log_tick_ms`
- `last_log_seq`
- `last_changed_mask`
- `last_fresh_mask`
- `last_max_delta_ms`

实现结果：

- 可以实时判断 logger 是否在持续工作
- 可以实时判断是否存在 stale / mixed / incoherent 行
- 可以从统计量上快速判断阶段 3 是否通过

## 3. 实测结果

### 3.1 Snapshot 结果

现场输出显示：

- 三路 `valid=1`
- 三路 `sample_seq` 持续增长
- `fresh=0x7`
- `max_delta_ms` 维持在合理范围，例如 `167ms`、`345ms`

说明：

- 三路数据持续更新
- 三路数据都在 freshness 窗口内
- 三路数据时间差未超过 coherent 判据窗口

### 3.2 FlowStat 结果

现场输出显示：

- `FLOW rows=90`
- `write_fail=0`
- `stale=0`
- `mixed=0`
- `coherent=90`
- `changed=0x7`
- `fresh=0x7`

说明：

- logger 持续写行
- 当前未出现写失败
- 当前未出现 stale 行
- 当前未出现 mixed 行
- 当前所有已统计日志行均满足 coherent 条件
- 最近一行三路传感器均发生更新，且均为 fresh 数据

### 3.3 DMA 状态结果

现场输出显示：

- `SPI1 ok` 持续增长
- `LSM calls ≈ SPI1 ok`
- `SPI2 ok ≈ 2 × SPI1 ok`
- `err=0`
- `fail=0`
- `to=0`
- `serr=0x0`

说明：

- LSM6DSOX 的 SPI1 DMA 持续正常运行
- H3LIS100DL 与 QMA6100P 的 SPI2 DMA 持续正常运行
- SPI2 双从设备共享总线调度稳定
- 未发现 DMA 错误、启动失败或超时

## 4. 偏离点与程度评估

本阶段总体实现与原目标高度一致，但仍存在以下偏离点。

### 4.1 USB 上传流与命令响应输出仍有交叉混杂

**现象：**

- 周期性 USB CSV 上传行会和 `snapshot / flowstat / stat` 命令响应交叉输出
- 观察上会出现命令结果与上传数据穿插

**偏离性质：**

- 表现层偏离
- 属于输出体验问题，不属于数据流正确性问题

**偏离程度：**

- 中等偏轻
- 会降低人工观察时的清晰度
- 但不影响功能正确性和阶段判定

**影响评估：**

- 不影响阶段 3 验收通过
- 建议作为下一阶段或收尾优化项处理，例如：
  - 命令模式与流模式分离
  - 增加上传开关
  - 增加输出前缀或分频道策略

### 4.2 `flowstat` 中 last 状态刷新观感不够直观

**现象：**

- 某些输出片段中，`FLOW last seq/tick` 显示值看起来没有与用户观察节奏同步刷新
- 这更像是查询瞬间和后台 logger 周期之间的采样时序现象，而不是统计失效

**偏离性质：**

- 观测体验偏离
- 不是底层统计错误

**偏离程度：**

- 轻微
- 不影响 `rows / updates / coherent / fresh` 等主判据使用

**影响评估：**

- 不影响阶段 3 验收通过
- 可作为后续易用性优化项处理

### 4.3 coherent 判据采用工程化窗口而非严格同步采样机制

**现状：**

当前 coherent 采用以下判定方式：

- 三路均为 fresh
- `max_delta_ms <= APP_SENSOR_COHERENT_WINDOW_MS`

即采用“检测与标记”方式，而不是引入更复杂的同步阻塞或统一触发采样机制。

**偏离性质：**

- 架构层的有意偏离
- 是设计选择，不是实现缺陷

**偏离程度：**

- 轻微到中等
- 相比“严格同步采样系统”，当前方案保守性略弱
- 但实现复杂度更低，且已满足阶段 3“可观测、可判定”的目标

**影响评估：**

- 不影响阶段 3 验收通过
- 若后续阶段要求更高精度时间对齐，再考虑统一触发或更强同步机制

### 4.4 当前验证以运行观测为主，编译闭环记录未单独固化进本阶段结论

**现状：**

- 阶段 3 当前结论主要来自现场 USB CDC / logger / DMA 输出验证
- 本轮验证记录中，编译日志闭环没有作为独立归档证据保留在总结内

**偏离性质：**

- 过程留痕偏离
- 不是代码功能偏离

**偏离程度：**

- 轻微
- 不影响现场判定结论
- 但在文档规范性上略有欠缺

**影响评估：**

- 不影响阶段 3 验收通过
- 后续如需要归档，可补充一份编译记录或版本号信息

---

## 5. 总体偏离程度结论

综合评估，本阶段偏离主要集中在：

- 输出观测体验
- 统计展示直观性
- 文档归档完整性

未发现以下类型问题：

- 数据流中断
- 三传感器更新停滞
- stale 数据持续堆积
- mixed 行持续出现
- logger 持续写失败
- DMA 错误、超时或启动失败

因此可判定：

**阶段 3 与目标相比仅存在轻微到中等的非阻塞性偏离，整体完成度高，且偏离不影响验收结论。**

---

## 6. 阶段结论

阶段 3“数据流优化”已完成，系统当前已具备以下能力：

- 三路传感器 snapshot 含元数据，可判断有效性、更新序号、更新时间
- logger 可对每行日志计算 fresh / changed / coherent 状态
- SD 卡 CSV 文件可直接作为阶段 3 离线验证依据
- USB CDC 可直接查看 snapshot、flow 状态与 DMA 运行状态

当前实测中：

- 三路数据持续更新
- `fresh=0x7`
- `changed=0x7`
- `write_fail=0`
- `stale=0`
- `mixed=0`
- `coherent` 持续增长
- DMA 错误项保持为 0

最终结论：

**阶段 3 已达到“可测试、可观测、可判定通过”的目标，可以正式关闭。**
